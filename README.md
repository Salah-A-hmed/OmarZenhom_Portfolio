# Omar Zenhom - Frontend Developer Portfolio

This is a dynamic, responsive, single-page portfolio website for Omar Zenhom, a Frontend Developer. The site is built with HTML, CSS, and Vanilla JavaScript to create an interactive and user-friendly experience.

It features a multi-section layout, a project showcase, a skills summary, and interactive elements like a light/dark mode theme switcher and a sticky navigation bar.

## Live Features

  * **Light/Dark Mode Toggle**: A theme switcher in the header allows users to toggle between light and dark modes. The user's preference is saved in their browser's local storage for future visits.
  * **Sticky Navigation Bar**: The header navigation bar is fixed to the top of the screen ("sticky") once the user scrolls past a certain point, ensuring easy navigation.
  * **Responsive Mobile Menu**: On smaller screens, the navigation bar collapses into a "hamburger" icon that toggles the mobile menu visibility when clicked.

## Website Sections

  * **Header**: Contains navigation links to all page sections and the light/dark mode toggle.
  * **Home**: A hero section introducing "Omar Zenhom" as a "Frontend Developer," with social media links and a "Download CV" button.
  * **About**: A brief personal introduction accompanied by a profile picture (`profile.jpg`).
  * **Skills**: A detailed breakdown of the developer's skills, separated into:
      * **Frontend Development**: HTML, CSS, JavaScript, Bootstrap, React, Angular.
      * **Backend Development**: Node.js, PHP, MySQL.
  * **Education**: A summary of educational background, including "ITI" and "Faculty of Education".
  * **Projects**: A grid showcase of three featured projects with images and descriptions:
      * Theatre Website
      * Flower Blog
      * Todo App
  * **Contact**: A final section with contact email information.

## Technology Stack

  * **HTML5**
  * **CSS3** (`style.css`)
  * **Vanilla JavaScript** (`script.js`)

## How to View

No installation, server, or build process is required.

1.  Ensure all files (especially the `assets` folder, `style.css`, and `script.js`) are in the same directory as `index.html`.
2.  Open the `index.html` file in any modern web browser.
